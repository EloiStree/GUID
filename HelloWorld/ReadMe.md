# Hello World Examples

This repository contains simple **Hello, World!** examples in multiple programming languages.

## Python

```python
print("Hello, World!")
```

---

## JavaScript

```javascript
console.log("Hello, World!");
```

---

## C#

```csharp
using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("Hello, World!");
    }
}
```

---

## Rust

```rust
fn main() {
    println!("Hello, World!");
}
```
